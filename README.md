# Mayodi Nawanjali — Professional Portfolio

A personal portfolio website built with HTML5, CSS3, and vanilla JavaScript, showcasing my education, technical skills, projects, activities, and career interests as an ICT undergraduate at the University of Vavuniya.

## Live Site

https://mayodinawanjali.github.io/mayodi-portfolio/

## GitHub Repository

https://github.com/mayodinawanjali/mayodi-portfolio

## Built With

* HTML5
* CSS3
* Vanilla JavaScript
* Google Fonts: Inter & JetBrains Mono

## Features

* Fully responsive design for mobile, tablet, and desktop
* Accessible navigation
* Keyboard focus states
* Active navigation highlighting
* Reduced-motion support
* Clean and responsive user interface
* Downloadable CV
* Project showcase
* Contact and social media links
* Deployed using GitHub Pages

## Running Locally

To run the portfolio locally, open `index.html` in a web browser.

Alternatively, you can use a local server:


python3 -m http.server 8000

Then open:


http://localhost:8000


## Deployment
